# Kebijakan keamanan

- Laporkan kerentanan atau kebocoran data secara privat lewat GitHub Security Advisories repo ini ("Report a vulnerability"), bukan lewat issue publik.
- Jika menemukan kredensial atau data subscriber/operator ter-commit, laporkan segera; kami akan merotasi kredensial dan membersihkan riwayat.
- Lab dirancang tanpa IP publik (akses hanya lewat IAP). Jangan membuka port ClickHouse/Grafana/VNC ke internet.
