# upstream-patches (AGPL-3.0)

Folder ini untuk patch terhadap proyek upstream berlisensi AGPL-3.0 (Open5GS, srsRAN).
Isi folder ini berlisensi **AGPL-3.0** (lihat [LICENSE](LICENSE)), **bukan** Apache-2.0 seperti bagian repo lainnya.

Konvensi: `upstream-patches/<proyek>/<versi>/<nomor>-<judul>.patch` + README berisi tujuan, versi dasar, dan status upstreaming.
